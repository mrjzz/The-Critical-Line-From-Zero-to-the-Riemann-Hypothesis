# 从零探索黎曼猜想

这个项目记录一次科普视频的前期研究：从亲手数素数开始，弄清黎曼猜想究竟要求证明什么，以及为什么检查再多零点也不足以证明它。当前材料按阅读用途整理，视频稿仍是草稿。

## 从哪里读起

1. **先看一道台阶。** 数论学家 Alex Kontorovich 的讲解中，02:47 可以看到素数计数台阶，12:58 换成加权计数，13:47 开始把零点的贡献叠上去。这三处值得连起来看。[中文分段稿](refs/transcripts/Quanta-RH.zh.md) · [英文逐句字幕](refs/transcripts/Quanta-RH.en.txt)
2. **再看零点画在哪儿。** 3Blue1Brown 用两个平面画复函数，07:49 开始看网格变形，16:09 回到解析延拓，18:19 给出临界线上的准确断言。[中文字幕阅读版](refs/transcripts/3Blue1Brown-zeta.zh.md)
3. **接着听陶哲轩讲反例。** 计算机找到一个线外零点就能推翻猜想，检查再多线上零点却无法证明猜想。听完这两分钟，再试着用自己的话解释两件事为什么不对称。[陶哲轩访谈文字稿](refs/transcripts/BV1coy8zQE93.md)
